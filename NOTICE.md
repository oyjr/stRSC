# Attribution and data terms

stRSC source code is distributed under the [MIT license](LICENSE).

Python dependencies retain their respective licenses. They are declared in
`pyproject.toml`; the figure scripts list theirs in `paper/requirements.txt`.

Model adapters integrate upstream implementations installed from their original
repositories. Those implementations, pretrained weights and datasets retain
their providers' terms.

Data sources, example assets and access requirements are described in
[DATA_SOURCES.md](DATA_SOURCES.md).
